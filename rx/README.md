# rx

TUI-меню для запуска команд из YAML. Слева — пункты меню, справа — история запусков и их вывод.

```bash
cargo run --manifest-path rx/Cargo.toml
# или
rx [path/to/menu.yaml]
```

Без аргумента читается `menu.yaml` в текущей директории.

## Формат `menu.yaml`

Список пунктов. У каждого обязательны `cmd` и `label`:

```yaml
- cmd: echo hello
  label: hello

- cmd: /home/kaineer/bin/shed
  label: shed
  live: true

- cmd: sleep 5 && echo done
  label: slow
  stream: true   # то же, что live: true
```

| Поле | Тип | Описание |
|------|-----|----------|
| `cmd` | string | Команда для `sh -c` |
| `label` | string | Подпись в левом списке |
| `live` | bool | Показывать stdout в правой панели по мере выполнения (по умолчанию `false`) |
| `stream` | bool | Алиас для `live` |

При `live`/`stream` запись появляется сразу после старта, вывод обновляется на лету (в том числе прогресс на `\r`). Без флага результат показывается только после завершения.

## Интерфейс

Две панели. Фокус — Tab. Ширину меняют перетаскиванием разделителя.

### Клавиатура

| Клавиша | Действие |
|---------|----------|
| `j` / `↓` | Вниз (в правой панели в режиме тела — скролл вниз) |
| `k` / `↑` | Вверх (в режиме тела — скролл вверх) |
| `gg` | К первому элементу текущей панели |
| `G` | К последнему элементу |
| Space / Enter / `l` | Слева — запустить; справа — цикл Collapsed → Preview → Full |
| Tab | Переключить фокус левая ↔ правая |
| `r` | Перечитать файл меню |
| `q` / Esc | Выход |

### Мышь

- **ЛКМ** по пункту слева — выделить; по запуску справа — выделить (в списке)
- **ПКМ** слева — выделить и запустить; справа по выделенному — цикл раскрытия
- **Перетаскивание** разделителя — ширина левой панели

### Правая панель

Для выбранного пункта слева показываются его запуски (свежие сверху). У каждого:

- шапка: статус (`✓` / `✗` / спиннер для live), время старта, число строк;
- **Collapsed** — только шапка;
- **Preview** — первые ~12 строк;
- **Full** — весь вывод, `j`/`k` скроллят.

Пока идёт `live`-команда, панель открывается в Full и следует за хвостом вывода.
