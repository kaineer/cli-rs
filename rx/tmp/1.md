# Разбиваем на модули

Хорошая идея — разделим на:
- `main.rs` — точка входа, настройка терминала, главный цикл
- `app.rs` — состояние `App` и его методы (навигация и т.п.)
- `config.rs` — загрузка YAML
- `ui.rs` — рендеринг
- `event.rs` — обработка клавиш и мыши
- `run.rs` (или оставим цикл в `main.rs`) — цикл обработки событий

Предлагаю структуру:

```
src/
├── main.rs
├── app.rs
├── config.rs
├── event.rs
├── ui.rs
└── run.rs
```

## `src/config.rs`

```rust
use std::{fs::File, io::BufReader, path::PathBuf};

use anyhow::{Context, Result};
use serde::Deserialize;

#[derive(Debug, Deserialize, Clone)]
pub struct MenuEntry {
    pub cmd: String,
    pub label: String,
}

pub fn load_entries(path: &PathBuf) -> Result<Vec<MenuEntry>> {
    let file = File::open(path)
        .with_context(|| format!("Не удалось открыть файл {:?}", path))?;
    let reader = BufReader::new(file);
    let entries: Vec<MenuEntry> =
        serde_yaml::from_reader(reader).with_context(|| "Не удалось распарсить YAML")?;
    Ok(entries)
}
```

## `src/app.rs`

```rust
use crate::config::MenuEntry;

pub struct App {
    pub entries: Vec<MenuEntry>,
    pub list_state: ratatui::widgets::ListState,
    /// Ширина левой панели в колонках
    pub left_width: u16,
    /// Флаг: тащим ли разделитель мышью
    pub dragging: bool,
    /// Общая ширина области (обновляется при рендере)
    pub area_width: u16,
    /// Статус-строка
    pub status: String,
    /// Признак запроса на выход
    pub should_quit: bool,
}

impl App {
    pub fn new(entries: Vec<MenuEntry>) -> Self {
        let mut list_state = ratatui::widgets::ListState::default();
        if !entries.is_empty() {
            list_state.select(Some(0));
        }
        Self {
            entries,
            list_state,
            left_width: 12,
            dragging: false,
            area_width: 80,
            status: String::new(),
            should_quit: false,
        }
    }

    pub fn next(&mut self) {
        if self.entries.is_empty() {
            return;
        }
        let i = match self.list_state.selected() {
            Some(i) => (i + 1) % self.entries.len(),
            None => 0,
        };
        self.list_state.select(Some(i));
    }

    pub fn previous(&mut self) {
        if self.entries.is_empty() {
            return;
        }
        let len = self.entries.len();
        let i = match self.list_state.selected() {
            Some(0) => len - 1,
            Some(i) => i - 1,
            None => 0,
        };
        self.list_state.select(Some(i));
    }

    pub fn selected_entry(&self) -> Option<&MenuEntry> {
        self.list_state
            .selected()
            .and_then(|i| self.entries.get(i))
    }

    pub fn quit(&mut self) {
        self.should_quit = true;
    }
}
```

## `src/event.rs`

```rust
use anyhow::Result;
use crossterm::event::{
    self, Event, KeyCode, MouseButton, MouseEventKind,
};
use std::time::Duration;

use crate::app::App;

/// Ждём событие не дольше `timeout`. Возвращает Ok(true), если что-то
/// обработали, Ok(false) — если событий не было.
pub fn handle_events(app: &mut App, timeout: Duration) -> Result<()> {
    if !event::poll(timeout)? {
        return Ok(());
    }
    match event::read()? {
        Event::Key(key) => handle_key(app, key.code),
        Event::Mouse(mouse) => handle_mouse(app, mouse),
        _ => {}
    }
    Ok(())
}

fn handle_key(app: &mut App, code: KeyCode) {
    match code {
        KeyCode::Char('q') | KeyCode::Esc => app.quit(),
        KeyCode::Down | KeyCode::Char('j') => app.next(),
        KeyCode::Up | KeyCode::Char('k') => app.previous(),
        KeyCode::Enter => {
            if let Some(e) = app.selected_entry() {
                app.status = format!("Запустить: {} -> {}", e.label, e.cmd);
            }
        }
        _ => {}
    }
}

fn handle_mouse(app: &mut App, mouse: crossterm::event::MouseEvent) {
    match mouse.kind {
        MouseEventKind::Down(MouseButton::Left) => {
            // Если кликнули по вертикальной границе divider'а — начинаем drag
            let divider_x = app.left_width as i32;
            if (mouse.column as i32 - divider_x).abs() <= 1 {
                app.dragging = true;
            }
        }
        MouseEventKind::Drag(MouseButton::Left) if app.dragging => {
            let new_width = mouse.column.min(app.area_width.saturating_sub(1));
            app.left_width = new_width.max(4);
        }
        MouseEventKind::Up(MouseButton::Left) => {
            app.dragging = false;
        }
        _ => {}
    }
}
```

## `src/ui.rs`

```rust
use ratatui::{
    layout::{Constraint, Direction, Layout},
    style::{Color, Modifier, Style},
    text::{Line, Span},
    widgets::{List, ListItem, Paragraph},
    Frame,
};

use crate::app::App;

pub fn draw(f: &mut Frame, app: &mut App) {
    let size = f.area();
    app.area_width = size.width;

    let vertical = Layout::default()
        .direction(Direction::Vertical)
        .constraints([Constraint::Min(1), Constraint::Length(1)])
        .split(size);

    let main_area = vertical[0];
    let status_area = vertical[1];

    let max_left = main_area.width.saturating_sub(1);
    if app.left_width > max_left {
        app.left_width = max_left;
    }

    let horizontal = Layout::default()
        .direction(Direction::Horizontal)
        .constraints([
            Constraint::Length(app.left_width),
            Constraint::Length(1),
            Constraint::Min(1),
        ])
        .split(main_area);

    let left_area = horizontal[0];
    let divider_area = horizontal[1];
    let right_area = horizontal[2];

    draw_left(f, app, left_area);
    draw_divider(f, app, divider_area);
    draw_right(f, app, right_area);
    draw_status(f, app, status_area);
}

fn draw_left(f: &mut Frame, app: &mut App, area: ratatui::layout::Rect) {
    let items: Vec<ListItem> = app
        .entries
        .iter()
        .map(|e| ListItem::new(Line::from(Span::raw(e.label.clone()))))
        .collect();

    let list = List::new(items)
        .highlight_style(
            Style::default()
                .bg(Color::Blue)
                .fg(Color::White)
                .add_modifier(Modifier::BOLD),
        )
        .highlight_symbol("> ");

    f.render_stateful_widget(list, area, &mut app.list_state);
}

fn draw_divider(f: &mut Frame, app: &App, area: ratatui::layout::Rect) {
    let divider_style = if app.dragging {
        Style::default()
            .fg(Color::Yellow)
            .add_modifier(Modifier::BOLD)
    } else {
        Style::default().fg(Color::Gray)
    };

    let divider_lines: Vec<Line> = (0..area.height)
        .map(|_| Line::from(Span::styled("│", divider_style)))
        .collect();
    let divider = Paragraph::new(divider_lines);
    f.render_widget(divider, area);
}

fn draw_right(f: &mut Frame, app: &App, area: ratatui::layout::Rect) {
    let right_text = match app.selected_entry() {
        Some(e) => format!("cmd:   {}\nlabel: {}", e.cmd, e.label),
        None => "Нет элементов".to_string(),
    };
    let right = Paragraph::new(right_text);
    f.render_widget(right, area);
}

fn draw_status(f: &mut Frame, app: &App, area: ratatui::layout::Rect) {
    let status_line = if app.status.is_empty() {
        "↑/↓ — навигация, Enter — выбрать, q — выход, тяни разделитель мышью".to_string()
    } else {
        app.status.clone()
    };
    let status = Paragraph::new(status_line).style(Style::default().fg(Color::Gray));
    f.render_widget(status, area);
}
```

## `src/run.rs`

```rust
use std::time::Duration;

use anyhow::Result;
use ratatui::{backend::Backend, Terminal};

use crate::{app::App, event, ui};

pub fn run<B: Backend>(terminal: &mut Terminal<B>, app: &mut App) -> Result<()> {
    loop {
        terminal.draw(|f| ui::draw(f, app))?;
        event::handle_events(app, Duration::from_millis(200))?;
        if app.should_quit {
            return Ok(());
        }
    }
}
```

## `src/main.rs`

```rust
mod app;
mod config;
mod event;
mod run;
mod ui;

use std::{
    io::{self, stdout},
    path::PathBuf,
};

use anyhow::Result;
use crossterm::{
    execute,
    terminal::{disable_raw_mode, enable_raw_mode, EnterAlternateScreen, LeaveAlternateScreen},
};
use ratatui::{backend::CrosstermBackend, Terminal};

use crate::{app::App, config::load_entries};

fn main() -> Result<()> {
    let path = std::env::args()
        .nth(1)
        .map(PathBuf::from)
        .unwrap_or_else(|| PathBuf::from("menu.yaml"));

    let entries = load_entries(&path)?;

    enable_raw_mode()?;
    let mut out = stdout();
    execute!(out, EnterAlternateScreen, crossterm::event::EnableMouseCapture)?;
    let backend = CrosstermBackend::new(out);
    let mut terminal = Terminal::new(backend)?;

    let mut app = App::new(entries);
    let res = run::run(&mut terminal, &mut app);

    disable_raw_mode()?;
    execute!(
        terminal.backend_mut(),
        LeaveAlternateScreen,
        crossterm::event::DisableMouseCapture
    )?;
    terminal.show_cursor()?;

    if let Err(err) = res {
        eprintln!("Ошибка: {err:?}");
    }
    Ok(())
}
```

## Что получилось

| Модуль | Ответственность |
|--------|-----------------|
| `main.rs` | Парсинг аргументов, настройка/восстановление терминала |
| `config.rs` | YAML → `Vec<MenuEntry>` |
| `app.rs` | Состояние и «доменные» операции (`next`, `previous`, `selected_entry`) |
| `event.rs` | crossterm → вызовы методов `App` (клавиши + мышь) |
| `ui.rs` | Отрисовка; **не** меняет состояние, кроме `area_width` |
| `run.rs` | Главный цикл `draw → handle_events → проверка quit` |

Замечания и варианты дальнейшего рефакторинга:

- **`ui` слегка мутирует `App`** (`area_width`, `left_width` clamp). Это прагматично, но если хочется чистоты — можно возвращать `Rect`'ы из layout-функции и передавать их в event, но обычно так не делают. Ещё вариант — хранить `area_width` в отдельной структуре `LayoutInfo` или вычислять размеры в `run` и передавать в `draw` аргументом.
- **`should_quit`** вместо возврата `Result<bool>` из `handle_events` — так `App` целиком описывает своё состояние, а `run` просто проверяет флаг.
- Если хочешь чистые границы — `event.rs` может возвращать `Option<Action>` (enum `Action { Quit, Next, Prev, Activate, DragStart, DragTo(u16), DragEnd }`), а `run` уже применяет его к `App`. Тогда `event.rs` вообще не знает про `App`, а `App` получает метод `apply(action)`. Это следующий логичный шаг, если планируешь тесты.
