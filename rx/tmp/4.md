# Правая панель: `✓/✗ HH:MM:SS N lines`

Делаем `draw_right` так, чтобы в шапке шла строка с символом, временем старта и количеством строк stdout, а ниже — уже привычные `cmd`/`label` (или что захочешь).

Понадобится превратить `SystemTime` в `HH:MM:SS`. В `std` нет прямого форматтера; либо тянем `chrono`/`time`, либо пишем вручную через `UNIX_EPOCH` и модулярную арифметику. Для «только часы:минуты:секунды локального времени» самое простое без зависимостей — использовать `chrono`, но если не хочется добавлять крейт ради одной строки, можно посчитать от `SystemTime::now().duration_since(UNIX_EPOCH)` и взять остаток от суток. Однако это будет **UTC**, а не локальное время. С `chrono` — одна строка и корректно.

Предлагаю добавить `chrono` — это самый беспроблемный вариант.

use ratatui::{

    Frame,

```rust
fn draw_right(f: &mut Frame, app: &App, area: Rect) {
    let Some(idx) = app.list_state.selected() else {
        f.render_widget(Paragraph::new("Нет элементов"), area);
        return;
    };
    let entry = &app.entries[idx];

    let mut lines: Vec<Line> = Vec::new();

    match app.last_run_for(idx) {
        Some(run) => {
            let sym = if run.ok { "✓" } else { "✗" };
            let color = if run.ok { Color::Green } else { Color::Red };

            // SystemTime -> chrono::DateTime<Local>
            let started: DateTime<Local> = run.started_at.into();
            let hhmmss = started.format("%H:%M:%S").to_string();

            let stdout_lines = run.stdout.lines().count();
            let plural = plural_ru(stdout_lines); // "строк", "строки", "строка"

            lines.push(Line::from(vec![
                Span::styled(sym, Style::default().fg(color).add_modifier(Modifier::BOLD)),
                Span::raw(" "),
                Span::styled(hhmmss, Style::default().fg(Color::Gray)),
                Span::raw(" "),
                Span::styled(
                    format!("{stdout_lines} {plural}"),
                    Style::default().fg(Color::Gray),
                ),
            ]));
            lines.push(Line::from(""));
        }
        None => {
            lines.push(Line::from(Span::styled(
                "(ещё не запускалось)",
                Style::default().fg(Color::DarkGray),
            )));
            lines.push(Line::from(""));
        }
    }

    lines.push(Line::from(format!("cmd:   {}", entry.cmd)));
    lines.push(Line::from(format!("label: {}", entry.label)));

    f.render_widget(Paragraph::new(lines), area);
}

/// «1 строка», «2 строки», «5 строк» — для аккуратной подписи.
fn plural_ru(n: usize) -> &'static str {
    let n10 = n % 10;
    let n100 = n % 100;
    if n10 == 1 && n100 != 11 {
        "строка"
    } else if (2..=4).contains(&n10) && !(12..=14).contains(&n100) {
        "строки"
    } else {
        "строк"
    }
}
```

## Что тут важно

1. **`SystemTime` → `chrono::DateTime<Local>`.** `chrono` реализует `From<SystemTime> for DateTime<Local>` и `for DateTime<Utc>`. Импорт `Local` даёт локальное время пользователя — то есть то, что он ожидает увидеть. Если хочется UTC — замени на `chrono::Utc`.

2. **`format("%H:%M:%S")`** — часы:минуты:секунды с ведущими нулями, ровно `HH:MM:SS`. Если нужны ещё и сутки для «вчерашних» запусков — легко расширить до `%d.%m %H:%M:%S` или условно показывать дату, если запуск не сегодня. Пока делаем ровно как просили.

3. **`run.stdout.lines().count()`** — количество строк в сохранённом stdout. Тут есть тонкость: наш читающий поток в `app.rs` складывает по одной строке и после каждой добавляет `\n`, так что `lines()` вернёт ровно то количество, сколько строк пришло. Если последняя строка была без завершающего `\n` — мы всё равно добавили `\n`, так что посчитается корректно. Единый вариант — читать байты и складывать как есть, но тогда пришлось бы отдельно считать строки; текущий подход проще.

4. **`plural_ru`** — по-русски «1 строка / 2 строки / 5 строк». Если хочешь по-английски (`1 line / 2 lines`) — замени тело функции на `if n == 1 { "line" } else { "lines" }`. Если предпочитаешь без слова — просто `format!("{stdout_lines}L")` или `format!("{stdout_lines}")`.

5. **`Line::from("")`** — пустая строка-разделитель между шапкой и `cmd/label`. Можно убрать, если хочется плотнее.

6. **Предупреждения `dead_code` частично уйдут.** Теперь читаются: `ok` (через `run.ok`), `started_at`, `stdout`. Всё ещё не читаются: `entry_idx`, `finished_at`, `duration`, `exit_code`, `stderr`. `finished_at` и `duration` уже используются в `draw_left` (через `finished_at.elapsed()`), так что фактически останутся висеть только `entry_idx`, `exit_code`, `stderr`. Когда появится журнал или расширенная карточка — они тоже уйдут. Пока можно оставить как есть.

## Мелочи, о которых стоит подумать заранее

- **Формат времени «запуска» vs «завершения».** Ты попросил именно дату запуска. Если позже решишь, что интереснее момент завершения — в `RunRecord` уже есть `finished_at`, заменишь `run.started_at.into()` на `run.finished_at.into()`. Плюс `duration` даст понять, сколько шло: `format!("{:?}", run.duration)` — компактно (например, `1.234s`).
- **Очень длинный stdout** (десятки тысяч строк) — `lines().count()` работает по строкам, это O(размер) на каждую отрисовку (80 мс). При больших объёмах может ощутимо «кушать» CPU. Если станет проблемой — посчитай один раз при формировании `RunRecord` и положи `stdout_lines: usize` в структуру. Заодно и `dead_code` потихоньку рассосётся.
- **Ширина правой панели.** Длинные `cmd`/`label` не будут переноситься сами (у `Paragraph` перенос по умолчанию выключен). Если хочется — добавь `.wrap(ratatui::widgets::Wrap { trim: true })` и `Paragraph::new(lines).wrap(...)`.
