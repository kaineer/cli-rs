# Запуск команды на `Space`/`Enter`/`l` со спиннером и статусом

Хорошая задача. Разобьём её аккуратно:

1. В `MenuEntry` добавляем рантайм-состояние (`EntryState`) — но так как `MenuEntry` приходит из YAML и не должен содержать UI-полей, заведём отдельный `Vec<EntryState>` в `App`, параллельный `entries`.
2. В `App` заводим `std::process::Child` для текущего запущенного процесса и время старта.
3. Раз в тик главного цикла (сейчас — каждые 200 мс) проверяем `child.try_wait()` и обновляем состояние.
4. В `ui::draw_left` справа от метки рисуем спиннер / check / cross + длительность.
5. `Enter`/`Space`/`l` запускают команду; одновременно может работать только одна — при попытке запустить вторую игнорируем (или можно разрешить несколько — см. заметки в конце).

## `src/app.rs`

```rust
use std::process::{Child, Command};
use std::time::{Duration, Instant};

use ratatui::widgets::ListState;

use crate::config::MenuEntry;

/// Рантайм-состояние одной записи списка.
pub enum EntryState {
    Idle,
    Running { started: Instant },
    Done { ok: bool, elapsed: Duration },
}

pub struct App {
    pub entries: Vec<MenuEntry>,
    /// Параллельный `entries` вектор состояний.
    pub states: Vec<EntryState>,
    pub list_state: ListState,
    pub left_width: u16,
    pub dragging: bool,
    pub area_width: u16,
    pub status: String,
    pub should_quit: bool,

    /// Запущенный процесс (не более одного одновременно).
    running: Option<(usize, Child, Instant)>,
    /// Номер тика для спиннера.
    pub tick: u64,
}

impl App {
    pub fn new(entries: Vec<MenuEntry>) -> Self {
        let states = entries.iter().map(|_| EntryState::Idle).collect::<Vec<_>>();
        let mut list_state = ListState::default();
        if !entries.is_empty() {
            list_state.select(Some(0));
        }
        Self {
            entries,
            states,
            list_state,
            left_width: 12,
            dragging: false,
            area_width: 80,
            status: String::new(),
            should_quit: false,
            running: None,
            tick: 0,
        }
    }

    pub fn next(&mut self) {
        if self.entries.is_empty() {
            return;
        }
        let i = match self.list_state.selected() {
            Some(i) => (i + 1) % self.entries.len(),
            None => 0,
        };
        self.list_state.select(Some(i));
    }

    pub fn previous(&mut self) {
        if self.entries.is_empty() {
            return;
        }
        let len = self.entries.len();
        let i = match self.list_state.selected() {
            Some(0) => len - 1,
            Some(i) => i - 1,
            None => 0,
        };
        self.list_state.select(Some(i));
    }

    pub fn selected_entry(&self) -> Option<&MenuEntry> {
        self.list_state
            .selected()
            .and_then(|i| self.entries.get(i))
    }

    pub fn quit(&mut self) {
        self.should_quit = true;
    }

    /// Тик главного цикла: двигаем спиннер и проверяем завершение процесса.
    pub fn tick(&mut self) {
        self.tick = self.tick.wrapping_add(1);
        self.poll_running();
    }

    /// Запустить команду по индексу выбранной записи.
    pub fn activate_selected(&mut self) {
        let Some(idx) = self.list_state.selected() else {
            return;
        };
        self.activate(idx);
    }

    fn activate(&mut self, idx: usize) {
        if self.running.is_some() {
            self.status = "Уже выполняется другая команда".to_string();
            return;
        }
        // Если элемент не Idle — тоже ничего не делаем (перезапускать Completed? — см. заметки).
        if !matches!(self.states.get(idx), Some(EntryState::Idle)) {
            return;
        }

        let cmd = self.entries[idx].cmd.clone();

        let child = match Command::new("sh").arg("-c").arg(&cmd).spawn() {
            Ok(child) => child,
            Err(e) => {
                self.status = format!("Ошибка запуска: {e}");
                self.states[idx] = EntryState::Done {
                    ok: false,
                    elapsed: Duration::ZERO,
                };
                return;
            }
        };

        let now = Instant::now();
        self.states[idx] = EntryState::Running { started: now };
        self.running = Some((idx, child, now));
        self.status = format!("Запущено: {}", self.entries[idx].label);
    }

    /// Проверяет, не завершился ли текущий процесс.
    fn poll_running(&mut self) {
        let Some((idx, child, started)) = self.running.as_mut() else {
            return;
        };

        match child.try_wait() {
            Ok(Some(exit_status)) => {
                let elapsed = started.elapsed();
                let ok = exit_status.success();
                self.states[*idx] = EntryState::Done { ok, elapsed };
                self.status = format!(
                    "{} {} завершена за {}",
                    self.entries[*idx].label,
                    if ok { "ok" } else { "ошибка" },
                    format_duration(elapsed),
                );
                self.running = None;
            }
            Ok(None) => {
                // ещё работает — состояние уже Running
            }
            Err(e) => {
                let elapsed = started.elapsed();
                self.states[*idx] = EntryState::Done { ok: false, elapsed };
                self.status = format!("Ошибка ожидания процесса: {e}");
                self.running = None;
            }
        }
    }
}

/// Формат длительности для строки статуса рядом с check/cross.
/// До 5 минут: "5s", "10s", ..., "60s"→"1m", "2m", ...
/// После 5 минут возвращает None (не показываем).
pub fn format_duration(d: Duration) -> String {
    let total_secs = d.as_secs();
    if total_secs < 60 {
        format!("{total_secs}s")
    } else if total_secs < 300 {
        format!("{}m", total_secs / 60)
    } else {
        String::new()
    }
}
```

## `src/event.rs`

```rust
use anyhow::Result;
use crossterm::event::{self, Event, KeyCode, MouseButton, MouseEventKind};
use std::time::Duration;

use crate::app::App;

pub fn handle_events(app: &mut App, timeout: Duration) -> Result<()> {
    if !event::poll(timeout)? {
        return Ok(());
    }
    match event::read()? {
        Event::Key(key) => handle_key(app, key.code),
        Event::Mouse(mouse) => handle_mouse(app, mouse),
        _ => {}
    }
    Ok(())
}

fn handle_key(app: &mut App, code: KeyCode) {
    match code {
        KeyCode::Char('q') | KeyCode::Esc => app.quit(),
        KeyCode::Down | KeyCode::Char('j') => app.next(),
        KeyCode::Up | KeyCode::Char('k') => app.previous(),
        KeyCode::Enter | KeyCode::Char(' ') | KeyCode::Char('l') => app.activate_selected(),
        _ => {}
    }
}

fn handle_mouse(app: &mut App, mouse: crossterm::event::MouseEvent) {
    match mouse.kind {
        MouseEventKind::Down(MouseButton::Left) => {
            let divider_x = app.left_width as i32;
            if (mouse.column as i32 - divider_x).abs() <= 1 {
                app.dragging = true;
            }
        }
        MouseEventKind::Drag(MouseButton::Left) if app.dragging => {
            let new_width = mouse.column.min(app.area_width.saturating_sub(1));
            app.left_width = new_width.max(4);
        }
        MouseEventKind::Up(MouseButton::Left) => {
            app.dragging = false;
        }
        _ => {}
    }
}
```

## `src/ui.rs`

```rust
use ratatui::{
    layout::{Constraint, Direction, Layout, Rect},
    style::{Color, Modifier, Style},
    text::{Line, Span},
    widgets::{List, ListItem, Paragraph},
    Frame,
};

use crate::app::{format_duration, App, EntryState};

pub fn draw(f: &mut Frame, app: &mut App) {
    let size = f.area();
    app.area_width = size.width;

    let vertical = Layout::default()
        .direction(Direction::Vertical)
        .constraints([Constraint::Min(1), Constraint::Length(1)])
        .split(size);

    let main_area = vertical[0];
    let status_area = vertical[1];

    let max_left = main_area.width.saturating_sub(1);
    if app.left_width > max_left {
        app.left_width = max_left;
    }

    let horizontal = Layout::default()
        .direction(Direction::Horizontal)
        .constraints([
            Constraint::Length(app.left_width),
            Constraint::Length(1),
            Constraint::Min(1),
        ])
        .split(main_area);

    draw_left(f, app, horizontal[0]);
    draw_divider(f, app, horizontal[1]);
    draw_right(f, app, horizontal[2]);
    draw_status(f, app, status_area);
}

/// Кадры спиннера (Braille Patterns, каждый символ — 1 колонка).
const SPINNER: [&str; 10] = ["⠋", "⠙", "⠹", "⠸", "⠼", "⠴", "⠦", "⠧", "⠇", "⠏"];

fn spinner_frame(tick: u64) -> &'static str {
    SPINNER[(tick as usize) % SPINNER.len()]
}

fn draw_left(f: &mut Frame, app: &mut App, area: Rect) {
    let items: Vec<ListItem> = app
        .entries
        .iter()
        .enumerate()
        .map(|(i, e)| {
            let marker = match &app.states[i] {
                EntryState::Idle => None,
                EntryState::Running { .. } => {
                    Some((spinner_frame(app.tick).to_string(), Color::Yellow, None))
                }
                EntryState::Done { ok, elapsed } => {
                    let sym = if *ok { "✓" } else { "✗" };
                    let color = if *ok { Color::Green } else { Color::Red };
                    let dur = format_duration(*elapsed);
                    let dur = if dur.is_empty() { None } else { Some(dur) };
                    Some((sym.to_string(), color, dur))
                }
            };

            let mut spans = vec![Span::raw(e.label.clone())];

            if let Some((sym, color, dur)) = marker {
                spans.push(Span::raw(" "));
                spans.push(Span::styled(sym, Style::default().fg(color)));
                if let Some(d) = dur {
                    spans.push(Span::raw(" "));
                    spans.push(Span::styled(d, Style::default().fg(Color::DarkGray)));
                }
            }

            ListItem::new(Line::from(spans))
        })
        .collect();

    let list = List::new(items)
        .highlight_style(
            Style::default()
                .bg(Color::Rgb(0x5e, 0x81, 0xac))
                .fg(Color::White)
                .add_modifier(Modifier::BOLD),
        )
        .highlight_symbol(" ");

    f.render_stateful_widget(list, area, &mut app.list_state);
}

fn draw_divider(f: &mut Frame, app: &App, area: Rect) {
    let divider_style = if app.dragging {
        Style::default().fg(Color::Yellow).add_modifier(Modifier::BOLD)
    } else {
        Style::default().fg(Color::Gray)
    };
    let divider_lines: Vec<Line> = (0..area.height)
        .map(|_| Line::from(Span::styled("│", divider_style)))
        .collect();
    f.render_widget(Paragraph::new(divider_lines), area);
}

fn draw_right(f: &mut Frame, app: &App, area: Rect) {
    let right_text = match app.selected_entry() {
        Some(e) => format!("cmd:   {}\nlabel: {}", e.cmd, e.label),
        None => "Нет элементов".to_string(),
    };
    f.render_widget(Paragraph::new(right_text), area);
}

fn draw_status(f: &mut Frame, app: &App, area: Rect) {
    let status_line = if app.status.is_empty() {
        "↑/↓ — навигация, Enter/Space/l — запустить, q — выход".to_string()
    } else {
        app.status.clone()
    };
    let status = Paragraph::new(status_line).style(Style::default().fg(Color::Gray));
    f.render_widget(status, area);
}
```

## `src/run.rs`

```rust
use std::time::Duration;

use anyhow::Result;
use ratatui::{backend::Backend, Terminal};

use crate::{app::App, event, ui};

pub fn run<B: Backend>(terminal: &mut Terminal<B>, app: &mut App) -> Result<()> {
    loop {
        app.tick();
        terminal.draw(|f| ui::draw(f, app))?;
        // 80 мс — компромисс: спиннер ~12 fps, реакция на клавиши мгновенная.
        event::handle_events(app, Duration::from_millis(80))?;
        if app.should_quit {
            return Ok(());
        }
    }
}
```

## Детали и тонкости

- **Почему `sh -c`?** YAML-значение `cmd` — это строка, которая может содержать аргументы и пайпы (`/bin/ls -la | head`). `Command::new("sh").arg("-c").arg(cmd)` корректно это выполняет. Если хочешь строго запускать файл без шелла — замени на `Command::new(&cmd)`. На Windows `sh -c` не сработает — там `cmd /C`, но для данной задачи предположим Unix-подобную систему.
- **Почему `try_wait` в главном потоке, а не отдельный поток?** Скрипты у нас короткие, и мы всё равно раз в ~80 мс крутим цикл. Так проще: нет мьютексов, нет каналов, `App` полностью под нашим контролем. Если команды станут долгими и понадобится параллелизм — переходи на `std::thread` + `mpsc::channel`, но это уже другая история.
- **Одновременно только один процесс.** Пока `running.is_some()`, новые запуски игнорируются со статусом «Уже выполняется другая команда». Если хочется позволить несколько параллельно — замени `Option<(usize, Child, Instant)>` на `Vec<(usize, Child, Instant)>` и в `poll_running` проходись по всем, а `states[i]` уже умеет отражать `Running`.
- **Повторный запуск завершённой команды.** Сейчас `activate` возвращает рано, если состояние не `Idle`. Если хочется перезапускать — убери эту проверку, но помни: тогда UI-статус предыдущего запуска затрётся. Разумный вариант — при перезапуске сбрасывать в `Running` (как и происходит) — просто убери проверку `if !matches!(self.states.get(idx), Some(EntryState::Idle))`.
- **Формат времени.** `format_duration`:
  - `< 60 s` → `Ns` (например, `5s`, `59s`)
  - `60..300 s` → `Nm` (например, `1m`, `4m`)
  - `≥ 300 s` → пустая строка (не показываем).
  
  Если нужно больше градаций (`1h`, `2h`) — допиши ветки.
- **Спиннер.** Использую Braille-паттерны (`⠋⠙⠹...`) — они моноширинные в большинстве современных шрифтов, и один символ = 1 колонка. Если шрифт не поддерживает Braille, можно заменить на `["|", "/", "-", "\\"]` — но тогда тоже один символ.
- **Цвета.** `✓` — `Green`, `✗` — `Red`, длительность — `DarkGray`, спиннер — `Yellow`. Если хочешь в Nord-палитре: `✓` → `#a3be8c`, `✗` → `#bf616a`, спиннер → `#ebcb8b`, длительность → `#4c566a`. Заменяются тривиально.
- **`ExitStatus::success()`** возвращает `true` при коде 0 — то, что нужно.
- **Клик мышью по элементу списка** пока не обрабатывается: мышь используется только для divider'а. Если захочешь добавить — в `handle_mouse` при `Down(Left)` проверь, что `mouse.column < app.left_width`, вычисли индекс по `mouse.row` с учётом скролла (у нас скролла нет, `ListState` сам центрирует выделение) и вызови `app.activate(idx)`. Это отдельная задача, легко расширяемая.

Собирай — теперь `Space`/`Enter`/`l` запускают команду, рядом с меткой появляется спиннер, потом `✓ 5s` или `✗ 12s`, а после 5 минут длительность исчезает.
