# vmd

Просмотр markdown в отдельном окне (gpui). Подсветки кода нет.

## Запуск

```bash
cargo run --manifest-path vmd/Cargo.toml -- README.md
cargo run --manifest-path vmd/Cargo.toml -- --fullscreen README.md
```

```
использование: vmd [--fullscreen] <файл.md>
```

`--fullscreen` (или `-f`) открывает окно на весь экран.

## Управление

| Клавиша | Действие |
|---------|----------|
| `j` / `↓` | Строка вниз |
| `k` / `↑` | Строка вверх |
| `Ctrl-d` / `Space` | Страница вниз |
| `Ctrl-u` | Страница вверх |
| `gg` | В начало |
| `G` | В конец |

Прокрутка колесом мыши тоже работает.

## Что отображается

- заголовки H1–H6 (размер и цвет по уровню)
- абзацы с переносом по словам
- маркированные и нумерованные списки, включая вложенные
- блоки кода в моноширинном шрифте на своём фоне; при `` ```lang `` —
  подсветка syntect (тема Nord)
- цитаты с цветной полосой слева
- таблицы (строки через `  `) и горизонтальные разделители
- строчная разметка: **жирный**, *курсив*, ***жирный курсив***,
  ~~зачёркнутый~~, `inline code` (моноширинный на своём фоне)
- ссылки `[текст](url)` и `<https://…>` — клик открывает браузер

Строчная разметка работает и в заголовках, и в пунктах списков, и в цитатах.
Вложенность сочетается — например, жирный фрагмент с кодом внутри:

**важно: `x = 1`**

Блок кода и inline-код используют один шрифт и один кегль (базовый размер
текста). Без языка или при неизвестном — цвет темы по умолчанию.

Цвета — палитра Nord.

### Про шрифты

Встроенное в gpui имя `.SystemUIFont` на Linux жёстко означает IBM Plex Sans.
Если его нет, gpui уходит в fallback и теряет начертания — жирный и курсив
выглядят как обычный текст. Поэтому `vmd` выбирает первое установленное
семейство из списка `Noto Sans` → `Inter` → `DejaVu Sans` → `Liberation Sans`.
Для inline-кода используется `FiraCode Nerd Font Mono`.

## Сборка

Требуется Linux с X11 или Wayland, Vulkan и fontconfig/freetype/xkbcommon.

`libc 0.2.186` и `mio 1.2.0` закреплены прямо в `Cargo.toml`: более новые
версии ломают сборку `xattr 0.2.3`, который тянет `gpui_http_client`
(в нём используется `libc::ENOATTR`, отсутствующий в Linux-таргете).

Пины нужны именно в `Cargo.toml`, а не только в `Cargo.lock`, потому что
`cargo install --path .` lock-файл не использует.

Установка:

```bash
cargo install --path vmd
```
