# cli-rs

rust rewrite for some handy tools

 * `es` -- tui to edit yaml/json/.envrc file
 * `jxr` -- takes jsx with inlined styles and transforms it to use vite css modules
 * `kana-converter` -- takes romaji and converts into kana/kanji
 * `nord` -- holds nord-theme data and performs some selection
 * `pe` -- project environment
 * `rx` -- menu handler
 * `smartlist` -- tui to select from command output
 * `vmd` -- markdown viewer
